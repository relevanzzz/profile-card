# profile-card

Eine schlichte Profilkarte als persönliche Startseite – umgesetzt mit reinem HTML und CSS, ohne Framework.

## Aufbau

```
profile-card/
├── index.html        Struktur der Seite
├── css/style.css     Styles
└── images/           Profilbild und Hintergrund
```

## Umgesetzt

- Zentrierte Karte mit Flexbox auf einem Vollbild-Hintergrund mit Farbverlauf
- Farben und Abstände als CSS-Variablen
- Runde Social-Media-Icons (Font Awesome) mit Hover-Effekt
- Responsive Layout für Smartphones über eine Media Query
- Einblend-Animation beim Laden, die bei `prefers-reduced-motion` abgeschaltet wird

## Lokal ansehen

`index.html` im Browser öffnen.
